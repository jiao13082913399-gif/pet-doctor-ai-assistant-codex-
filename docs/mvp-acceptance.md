# MVP 手动验收路径

本文档用于 `T21 Docker 部署与 MVP 验收`。验收目标是确认“录音 / 上传音频 -> 语音转写 -> AI 生成结果 -> 编辑 / 采纳 / 保存 / 导出 -> 智能回访转待办”的 MVP 闭环可以由测试人员完整走通。

## 验收前准备

1. 启动 Docker 服务：

```bash
./scripts/docker-up.sh
```

2. 打开 H5：

```text
http://localhost:8080
```

3. 使用 seed 测试账号登录：

```text
账号：demo_doctor
密码：demo_password
```

4. 准备一个本地音频文件，格式为 MP3、WAV 或 M4A，大小不超过 `MAX_AUDIO_SIZE_MB`，时长不超过 `MAX_AUDIO_DURATION_SECONDS`。

5. 若需要重新初始化验收数据，可停止服务后删除 Docker volume，再重新启动：

```bash
docker compose down -v
./scripts/docker-up.sh
```

## 验收路径

### 1. 登录系统

- 打开 `http://localhost:8080`。
- 输入 `demo_doctor / demo_password`。
- 点击登录。
- 预期：进入 Web H5 主工作台，顶部展示当前用户信息。

### 2. 首次登录确认隐私授权

- 首次进入主工作台时查看录音授权与隐私提示弹窗。
- 点击“我已知晓并确认”。
- 预期：弹窗关闭，后续同一用户本地再次进入不重复弹出。

### 3. 创建 Memory

- 进入侧边栏 `AI 搭档 / Memory`。
- 按页面提示填写或初始化个人 Memory。
- 保存后刷新页面。
- 预期：Memory 内容可保存并重新读取。

### 4. 进入 AI 录音页

- 点击侧边栏 `AI 录音 / 智能工牌`。
- 查看录音前隐私提示、开始录音按钮、上传录音入口和最近录音列表。
- 预期：页面不空白，录音和上传入口均可见。

### 5. 上传 MP3/WAV/M4A

- 点击上传录音。
- 选择准备好的 MP3、WAV 或 M4A 文件。
- 预期：上传成功后列表出现一条新录音，状态进入转写或生成流程；上传视频或不支持格式时显示明确错误。

### 6. 触发转写

- 上传成功后等待自动转写。
- 如状态失败，点击“重新尝试”。
- 预期：转写成功后录音详情中出现转写文本，失败时保留已上传录音并显示重试入口。

### 7. 生成总摘要和前五项结果

- 转写成功后等待默认 AI 生成完成。
- 进入录音详情。
- 预期：可看到总摘要，以及默认生成的五项业务结果：病历自动生成、沟通复盘、客户全景画像、升单机会挖掘、智能回访。

### 8. 查看七大 Tab

- 在录音详情页依次点击七个 Tab：
  - 病历自动生成
  - 沟通复盘
  - 客户全景画像
  - 升单机会挖掘
  - 智能回访
  - 医疗风险防控
  - 团队经验共享
- 预期：前五项展示已生成内容；医疗风险防控和团队经验共享展示“需主动生成”的提示。

### 9. 主动生成医疗风险防控

- 打开 `医疗风险防控` Tab。
- 点击立即生成。
- 预期：生成完成后展示风险点列表，并出现医疗内容需人工确认的强提示。

### 10. 主动生成团队经验共享

- 打开 `团队经验共享` Tab。
- 点击立即生成。
- 预期：生成完成后展示典型病例、优秀话术、处置路径、沟通技巧、可沉淀经验和脱敏建议等内容。

### 11. 编辑病历并保存

- 打开 `病历自动生成` Tab。
- 点击编辑，修改病历文本或 JSON 内容。
- 点击保存。
- 刷新或重新进入录音详情。
- 预期：修改内容被保存；页面继续提示 AI 内容需人工确认。

### 12. 采纳一个结果

- 任选一个已生成结果。
- 点击采纳。
- 预期：结果状态更新为已采纳或已确认，页面给出成功提示。

### 13. 不采纳一个结果并填写原因

- 任选另一个已生成结果。
- 点击不采纳。
- 选择或填写原因后提交。
- 预期：缺少原因时不允许提交；提交后结果状态更新为不采纳，并记录反馈。

### 14. 重新生成一个模块

- 任选一个已生成模块。
- 点击重新生成。
- 等待生成完成。
- 预期：模块内容更新，版本号递增，旧反馈记录不影响新结果查看。

### 15. 导出病历 PDF

- 打开 `病历自动生成` Tab。
- 点击导出 PDF。
- 预期：浏览器直接下载病历 PDF，内容包含宠主、宠物、医生 / 用户、生成时间、病历结构和医疗人工确认提示。

### 16. 导出客户画像图片/PDF

- 打开 `客户全景画像` Tab。
- 分别点击导出图片和导出 PDF。
- 预期：浏览器下载 PNG 图片和 PDF；导出内容按门店内部查看口径展示，并包含 AI 辅助提示。

### 17. 智能回访转待办

- 打开 `智能回访` Tab。
- 点击“一键转成待办”。
- 预期：创建待办成功，并保留宠主、宠物、回访内容和 due_time。

### 18. 在待办页勾选完成

- 进入侧边栏 `任务 / 待办`。
- 找到刚创建的回访待办。
- 点击完成或勾选完成。
- 预期：待办状态更新为已完成。

### 19. 删除录音并检查审计日志

- 回到 `AI 录音 / 智能工牌`。
- 删除一条录音。
- 使用管理员、院长账号或开发环境 token 调用：

```bash
curl -H "Authorization: Bearer <token>" http://localhost:8080/api/audit-logs
```

- 预期：可查到 `recording.delete` 审计日志，且包含删除前后的数据快照；普通用户在非开发环境不应拥有审计日志入口。

### 20. 查看资源库、项目空间、院长看板占位页

- 分别进入侧边栏 `资源库`、`项目空间`、`院长看板`。
- 预期：
  - 资源库显示暂未开放和未来资源类型。
  - 项目空间显示项目列表占位、新建项目入口预留和项目详情占位。
  - 院长看板显示 6 个指标卡和统计能力即将上线提示，不展示误导性真实数据。

### 21. 编译小程序端页面结构

- 在本地执行：

```bash
npm run build:mp-weixin -w frontend
```

- 预期：构建成功，产物生成到 `frontend/dist/build/mp-weixin`，包含首页、AI、我的三页 Tab 结构。

## 通过标准

- `docker compose up --build` 可以启动后端 API 和 H5 静态服务。
- `http://localhost:8080/api/health` 返回健康检查成功。
- `http://localhost:8080` 可以登录并完成完整 MVP 主流程。
- 录音上传、转写、默认生成、主动生成、编辑保存、采纳、不采纳、重新生成、导出、转待办、完成待办和删除录音均有明确成功或失败反馈。
- `docs/mvp-acceptance.md` 足以指导测试人员独立完成 MVP 验收。
